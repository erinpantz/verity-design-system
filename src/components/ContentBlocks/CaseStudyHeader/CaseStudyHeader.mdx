# CaseStudyHeader

The top of a case study: its title, large, and the facts about the project, like the role, team, and year.

<Canvas of={CaseStudyHeaderStories.Default} />

## When to use

- **Once, at the top of a case study page,** inside a `Container`, before the page’s first Section.
- **Not with a Hero.** Its heading is the page’s `<h1>`, and so is a Hero’s, so a page starts with a Hero or a CaseStudyHeader, never both.
- **Not for facts partway down a page.** Use a `Grid` of `MetaItem`s with `as="dl"`.

## Accessibility

A CaseStudyHeader renders a `<header>`: the page’s introduction. Its heading is the page’s `<h1>`, set in `display-default` like a Hero’s headline. The facts are a description list (`<dl>`): each fact’s title is a term (`<dt>`) and its value is the description (`<dd>`), so screen readers pair them.

| Situation | What to do | Example |
|---|---|---|
| Writing the heading | Say what the work achieved, in sentence case. It’s the page’s title for screen readers. | “Saving admin time and improving care quality” |
| Writing the facts | Keep each title to a word or two, in sentence case, and each value to one short line. List them in the order people should read them. | “Role,” “Lead product designer” |

## Facts

`facts` is a list of title and value pairs, shown as MetaItems in a `Grid` with `itemWidth="sm"`. Three facts sit in one row on a wide screen, and the row wraps on narrow ones. More facts make more columns, then wrap.

<Canvas of={CaseStudyHeaderStories.MoreFacts} />

## Space

A CaseStudyHeader fills the width it’s given and adds no space outside itself. Put it in a `Container`, which holds it to the same content column as the Sections below it.

| Space | Token |
|---|---|
| Between the heading and the facts | `--verity-spacing-lg` |
| Between the facts | `--verity-spacing-md`, from `Grid` |
| Text | The heading in `display-default` (`--verity-viewport-typography-display-default-*`), like Hero’s headline; the facts in the MetaItem text styles |

Nothing inside adds space of its own: the header’s gap is the only space between its parts.

## In Figma

| Figma | Code |
|---|---|
| Component `CaseStudyHeader` | `<CaseStudyHeader />` |
| Text layer `Heading`, in Display/Default | `heading`. Always the page’s `<h1>` in code. |
| Slot `Facts`, holding a Grid of MetaItems | `facts`: a list of title and value pairs, passed as data. CaseStudyHeader makes the Grid (`as="dl"`, `itemWidth="sm"`) and the MetaItems. In Figma, you fill the slot by hand. |
| The fixed width | Not in code: the header fills the width it’s given |
