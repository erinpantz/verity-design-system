# BackLink

A link back to the page above this one, with a back arrow, on a scrim. In Shell’s focused mode, it floats in the top-left corner in place of the nav.

<Canvas of={BackLinkStories.Default} />

## When to use

- **In Shell’s focused mode,** where Shell places it for you: set `mode="focused"` and `backLink` on Shell. See **Layout › Shell**.
- **To go back one level,** like from a case study to the portfolio. Name the page it goes to.
- **Not for links within a page or in running text.** Use `Link`.
- **Not for an action that changes the page.** Use `Button` or `IconButton`: a BackLink always goes somewhere.

## Accessibility

A BackLink renders an `<a href>`, so it works like any link: Enter follows it, and screen readers announce it as a link. Its name is its `label`. The arrow is decorative and hidden from screen readers, since “link” already says it goes somewhere.

| Situation | What to do | Example |
|---|---|---|
| Writing the label | Name the page it goes to, in a word or two, sentence case. Don’t add “Back to”: the arrow shows the direction, and the name stays short. | “Portfolio” |
| Choosing the href | The page above this one, not the browser’s history, so it works for someone who arrived from a search or a shared link | `href="/"` |

## States

The surface is always a scrim, so it stays readable over whatever scrolls under it, with a small shadow. Hover and press add a fill on top of the scrim, like `IconButton` with `background="scrim"`. On hover and focus it lifts with a larger shadow, like `PortfolioCard`.

| State | What changes | Tokens |
|---|---|---|
| Default | The scrim, a small shadow, and the arrow and label in the default content color | `--verity-color-background-scrim`, `--verity-shadow-sm-*`, `--verity-color-content-default` |
| Hover | It lifts, with the large shadow and a light fill over the scrim. Devices with a real pointer only, so a tap doesn’t leave it raised. | `--verity-motion-lift-sm` (4), `--verity-shadow-lg-*`, `--verity-color-background-transparent-medium` |
| Focus | The hover lift and shadow, plus the shared focus ring, which moves with it. Keyboard focus only, on every device. | `--verity-focus-ring-width`, `--verity-focus-ring-offset`, `--verity-color-border-focus` |
| Active | It settles back down with the small shadow, so pressing reads as pushing it in, and a stronger fill over the scrim | `--verity-shadow-sm-*`, `--verity-color-background-transparent-strong` |
| Disabled | None: a link back always goes somewhere | — |

## Motion

| What | How | Tokens |
|---|---|---|
| The lift | Up by `--verity-motion-lift-sm` on hover and focus, and back down on mouse out, blur, or press. No growth: at this size, PortfolioCard’s 2% wouldn’t show. | `--verity-motion-duration-playful`, `--verity-motion-easing-standard` |
| The shadow | Fades between states. The hover and press fills switch at once, like IconButton’s. | `--verity-motion-duration-fast`, `--verity-motion-easing-standard` |
| Reduce motion is on | No lift. The shadow fade stays, since it doesn’t move anything. | — |

**Only what you see moves.** The link is the hit area and stays still; the surface inside it (the scrim, the shadow, the fills, and the focus ring) is what lifts. If the whole 40px link moved, a pointer near its bottom edge could end up below it as it rose, end the hover, drop it back, and make it flicker.

In Shell’s focused mode it stays clear of the screen’s top edge when lifted, and nothing clips its shadow.

## Size and space

| What | Token |
|---|---|
| Height | `--verity-control-size-md` (40–44) |
| Side padding | `--verity-control-padding-x-md` |
| Between the arrow and the label | `--verity-control-gap` |
| Corners | `--verity-border-radius-md` |
| The arrow | `icon/back`, at `--verity-icon-size-sm` (20) |
| The label | `label-default` (`--verity-viewport-typography-label-default-*`) |

## Color

The label stays readable on the scrim even over a white picture: about 17:1 over the page’s background and over 8:1 over white, in both themes.
