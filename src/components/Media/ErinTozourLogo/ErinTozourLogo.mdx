# ErinTozourLogo

Erin Tozour’s name, drawn as a logo. It’s the site title in `MainNav`, in full or as just “Erin” where space is short. It’s set in Imperfecto, Erin’s own typeface.

<Canvas of={ErinTozourLogoStories.Default} />

## When to use

- **As the site title,** linking to the home page, as MainNav does.
- **Anywhere the site signs its name,** like the footer.
- **The first name (`name="first"`) where the full name doesn’t fit,** like MainNav’s short layout. Where both fit, use the full name.
- **Not as a small square mark,** like a badge or an avatar. Use ErinTozourBadge, the E on a round brand-colored badge.
- **Not for the Verity design system.** Verity has its own logo, in `brand/verity-logo.svg`.
- **Not as a heading.** The page’s heading is text, so it can be searched, translated, and resized.

## Accessibility

The logo renders an `<svg>` with `role="img"` and `aria-label="Erin Tozour"`, so screen readers read it as “Erin Tozour.” The first-name version has the same name: it’s the same logo, shortened to fit, and the site’s name doesn’t change with the space it has.

| Situation | What to do | Example |
|---|---|---|
| The logo is a link | Put it inside the link with nothing else. The link takes its name from the logo, “Erin Tozour.” | MainNav’s site title, linking home |
| The name is also written as text right next to it | Show one or the other, so screen readers don’t hear the name twice | A footer with the logo, not the logo and “Erin Tozour” |

## Name

| `name` | Draws | Width at 32px tall | Use for |
|---|---|---|---|
| `full` (default) | “Erin Tozour” | About 235px | Wherever it fits |
| `first` | “Erin” | About 78px | Narrow spaces, where the full name would crowd what’s beside it |

The first-name version has its own file, exported from Figma with the same height and with “Erin” in the same place as in the full logo, so at the same height the letters are the same size and sit in the same place. Switching between the two only cuts off or brings back “Tozour.”

## Size

The logo is as tall as its container, and its width follows, so it keeps its proportions. Set the height on the container, from a token: in MainNav, `--verity-main-nav-logo-height` (32px on XL and Large, 24px on Medium and Small). In a container with no height, the logo fills the width instead.

## Color

The logo is one color, `currentColor`, so it takes the text color of wherever it sits. In Figma, it uses `color/content/default`.

## Color cycle

The logo is the one place on every page that’s Erin’s own, and the accent colors are the brand’s personality, so on hover the name lights up in a wave of them. **While the link around it is hovered or has keyboard focus,** its letters cycle through the six content accents, a wave that travels from left to right along the name.

| What | How | Tokens |
|---|---|---|
| The colors | The six content accents in order, which follow the theme (in Blue: yellow, red, violet, green, orange, pink) | `--verity-color-content-accent-one` to `-six` |
| The wave | At each step, each letter shows the next accent, and each letter is one color behind the letter before it, so the colors travel to the right. Every letter switches at the same moment, with no blend. | `--verity-erin-tozour-logo-duration-color-step` (180ms) per step |
| Starting | Every letter takes its color at once, on hover (devices with a real pointer) or keyboard focus, and the wave runs as long as either lasts. Each hover picks the wave up where the last one left off. | — |
| Ending | The wave keeps running for a moment, then the letters fade back to the logo’s color. If the pointer comes back during that wait, nothing visible happens: the wave just keeps going, so a pointer slipping off the edge doesn’t make it flicker. | `--verity-motion-duration-fast` to wait, then `--verity-motion-duration-fast` to fade |
| Reduce motion is on | The letters take their colors, and they don’t move. They wait the same time before going back. | — |

- **Only inside a link that asks for it.** The link puts the trigger class (`erinTozourLogoTrigger`, from `logoTrigger.ts`) on itself, as `MainNav`’s home link does, like NavIcon’s poses follow their link. Anywhere else, the logo stays one color. The class isn’t exported from the library: MainNav is the one place the site shows the logo in a link.
- **It’s all CSS.** Each letter is numbered in reading order in `logoGlyphs.ts` (the exported files don’t list the letters in that order), and runs the same six-step cycle, started a step later than the letter before it. At rest the cycle is paused and adds no color, so the logo looks exactly as it always has.
- **Nothing else changes:** its size, its accessible name, “Erin Tozour,” and how it looks at rest.
