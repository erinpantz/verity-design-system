# Image

A picture that fills the width of whatever holds it, in one of three shapes. Its space is held while it loads, so the page doesn’t jump.

<Canvas of={ImageStories.Default} />

## When to use

- **For photos, screenshots, and illustrations** in a page’s content.
- **With a caption,** put it in a `MediaBlock`, which pairs the image with its caption.
- **For several images together,** use a `Gallery` of MediaBlocks.
- **Not for icons or logos.** Use `Icon`, or the logo components, which take the text color and stay sharp at any size.

## Accessibility

An Image renders an `<img>`. Its `alt` text is what screen readers read in its place, so `alt` is required.

| Situation | What to do | Example |
|---|---|---|
| The image shows something people need | Describe what it shows and why it’s there, in a sentence. Don’t start with “Image of.” | `alt="The setup screen, on step 2 of 5: Connect your bank"` |
| The image is decorative, or the text beside it says it all | Use an empty `alt=""`. Screen readers skip it. | A mood photo at the top of a section |
| The image has a caption | Still write `alt`. The caption adds context; `alt` says what’s in the picture. | A MediaBlock with the caption “Before the redesign” |
| The image is text, like a chart or a quote | Put the text in `alt`, or on the page next to it. | A screenshot of a key metric |

## Aspect ratio

The image fills its container’s width, and its height comes from the ratio. That height is reserved before the file arrives, so nothing below it moves while it loads.

| `aspectRatio` | Shape | Use for |
|---|---|---|
| `16:9` | The default. Wide. | Screenshots and wide photos |
| `3:2` | A little taller | Photos |
| `1:1` | Square | Portraits, details, and grids of thumbnails |

## Fit

How the picture fills its shape when the file’s own shape is different.

| `fit` | What it does | Use for |
|---|---|---|
| `cover` | The default. Fills the shape and crops what doesn’t fit. | Photos, where losing the edges is fine |
| `contain` | Shows the whole picture, with empty space around it | Screenshots, logos, and diagrams, where nothing should be cut off |

The space around a `contain` image is transparent, so the background behind it shows.

## Border radius

Images have rounded corners.

| `borderRadius` | Token | Use for |
|---|---|---|
| `md` | `--verity-border-radius-md` | The default: every image in a page’s content, on its own or in a `MediaBlock`, `Gallery`, or `MediaText` |
| `none` | `--verity-border-radius-none` | Square corners. Verity has no edge-to-edge layouts, so use `md` unless a design calls for square corners. |

<Canvas of={ImageStories.BorderRadiusNone} />

**Why rounded by default:** most images sit inside the page’s margins, and rounded corners match the site’s other rounded shapes, such as cards and buttons. Making `md` the default means it’s right without anyone setting it.

Animation follows the same rule.

## Loading

Images load lazily by default: the browser waits until an image is close to the screen, so the page opens faster. For an image at the very top of a page, use `loading="eager"`, so it appears right away.

Until the picture arrives, a `Skeleton` fills its shape, with the same ratio and corners, and is removed once the picture loads. If the file can’t load, the Skeleton’s base color stays without the shine, so it doesn’t look like it’s still on its way. Screen readers still read the `alt` text.

## In Figma

| Figma | Code |
|---|---|
| Component `Image` | `<Image />` |
| Property `Aspect ratio` | `aspectRatio`. `16:9` is the default in both. |
| Property `Border radius` | `borderRadius`. `md` is the default in both. |
| The image fill’s scale mode: Fill or Fit | `fit`: Fill → `cover`, Fit → `contain` |
| The image itself | `src` |
| Not in Figma | `alt`, which every image needs, and `loading` |
