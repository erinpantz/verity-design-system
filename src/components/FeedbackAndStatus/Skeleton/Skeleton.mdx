# Skeleton

A placeholder that holds the place of media while it loads: a block that pulses slowly between the subtle background color and a lighter shine.

<Canvas of={SkeletonStories.Default} />

## When to use

- **You usually don’t place it yourself.** `Image` shows a Skeleton until its picture loads, then removes it.
- **For other media that loads slowly,** place it in a container with the media’s shape. It fills the container and takes its corners.
- **Not for empty states or errors.** A Skeleton says “something is coming.” When nothing is, say so in text.

## Accessibility

A Skeleton renders a `<div>` with `aria-hidden="true"`, so screen readers skip it. It’s only decoration: the media it stands in for has its own accessible text, like an Image’s `alt`.

| Situation | What to do | Example |
|---|---|---|
| Someone has “reduce motion” turned on | Nothing. The pulse stops, and a flat block in the base color shows. | The macOS setting Reduce motion |
| The media failed to load | Turn off the pulse with `showShine={false}`, so it doesn’t look like it’s still loading. Image does this for you. | An image whose file is missing |

## Pulse

The whole block changes color: from the base to the shine, then back, taking `--verity-skeleton-duration` each way. It eases in and out, so it slows at each end, and it keeps going until the media arrives.

| Part | Token | Value |
|---|---|---|
| Base | `--verity-color-background-subtle` | The theme’s subtle background |
| Shine | `--verity-skeleton-color-shine` | A lighter step of the brand color, in each theme |
| Each way | `--verity-skeleton-duration` | 1500ms, so a full pulse takes 3 seconds |

| `showShine` | What it shows | Use for |
|---|---|---|
| `true` | The default. The pulsing block. | Media that’s on its way |
| `false` | A flat block in the base color | Media that failed to load |

<Canvas of={SkeletonStories.WithoutShine} />

## Size

A Skeleton fills its container’s width and height and takes its corners (`border-radius: inherit`). Give the container the media’s shape, such as an aspect ratio, and it matches. Inside an Image, it takes the Image’s `aspectRatio` and rounded corners.
