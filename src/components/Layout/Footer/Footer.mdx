# Footer

The site’s footer: a deep brand-colored block with an invitation to get in touch, an optional aside beside it for anything else, and the copyright line.

<Canvas of={FooterStories.Default} />

## When to use

- **Once per page, at the end,** after the page’s content. `Shell` puts it there.
- **Not for the end of a section or an article.** Use `Divider` and a `Section` there.

## Accessibility

Its links go through `LinkProvider`: with a site’s router, links to the site’s pages change the page in the app, and the résumé, email, and other sites stay plain links (see **Actions › LinkProvider**).

**No page links.** The Footer used to hold the site’s links in groups. With the nav fixed to the top of every page, they repeated what’s always on screen, so they’re gone (since 0.10.0). Put anything the nav doesn’t cover in the aside.

A Footer renders a `<footer>`. Outside `<main>`, it’s the page’s footer landmark (`contentinfo`), so screen readers can jump to it.

| Part | What it renders | What to do |
|---|---|---|
| Call to action heading | A level 3 `Heading` | Keep it short and inviting, like “Let’s work together” |
| Call to action button | A `Button` with `href`: a link that looks like a button | Start the label with a verb: “Book a meeting.” For a booking page on another site, set `opensInNewTab`. |
| Second action (optional) | An `IconButton` with `href`: a link that looks like an IconButton, named by its label, which is also its tooltip | Name the place it goes, like “LinkedIn.” With `opensInNewTab`, screen readers hear “LinkedIn (opens in a new tab).” |
| Aside (optional) | A `<div>` holding what you pass | Text with a `Link` in it, say. Its text takes the footer’s text style. A decorative mark, like `VerityMark`, is hidden from screen readers, so the text beside it does the talking. |
| Copyright | A paragraph: `© {year} {name}` | Pass only the name. The year comes from today’s date, so it never goes stale. |

## Width

The Footer is wide: it spans the page up to `--verity-content-wide-width` (1824), like a wide image, so it reads as the page’s closing band rather than one more block in the column. On Large and smaller, that’s the page’s full width inside the margins.

The call to action and the aside sit side by side on Large and XL, top-aligned, and stack on Medium and Small, where the link groups used to. The minimum widths change by breakpoint to make that happen, and the row only wraps when both parts can’t fit. That depends on the Footer’s own width, not the screen’s.

| Part | XL and Large / Medium / Small | Widest |
|---|---|---|
| Call to action | At least `--verity-footer-call-to-action-min-width` (300 / 320 / 240) | Its contents stop at `--verity-footer-call-to-action-max-width` (400), so its text keeps a comfortable line length |
| Aside | `--verity-footer-links-min-width` (432 / 480 / 240), but never narrower than `--verity-footer-call-to-action-max-width` (400): 432 / 480 / the full width on a phone | The same: it doesn’t grow |

On a screen narrower than a part’s width, that part is the full width instead.

Side by side, the call to action sits at the start and the aside at the end: the call to action takes the extra space (its text still stops at its max), so the aside ends at the Footer’s edge. Stacked, both start at the left. On a phone, the aside is as wide as the call to action, so the two line up.

**Why the aside uses the links’ token:** it takes the link groups’ place and wraps where they did. The token’s name still says “links” (see In Figma).

## Second action

`callToAction.secondaryAction` adds an `IconButton` right after the button, for a second, smaller way to get in touch, like LinkedIn. It’s the same size as the button (`md`: 40 on Large and XL, 44 on Medium and Small), `--verity-spacing-xs` after it.

It uses IconButton’s `none` background: no fill, the icon in `--verity-color-content-default`, and a see-through fill on hover and press. Next to the filled primary button, it reads as the quieter of the two, the way a secondary button would. Its focus ring is `--verity-color-border-focus`, like the button’s.

| Field | What it is |
|---|---|
| `icon` | Which icon, like `linkedin` |
| `label` | Its name for screen readers and its tooltip, like “LinkedIn” |
| `href` | Where it goes |
| `opensInNewTab` | For a page on another site, like a profile |

## Aside

`aside` is anything else, on the right: a line about the site, say, with a link in it. Its text takes the footer’s text style, `body-default` in `--verity-color-content-default`, and its links the footer’s link colors (see Color). What it holds stacks `--verity-spacing-sm` apart, as in the call to action, with no margins of its own, so a mark above a paragraph needs no layout.

```tsx
<Footer
  aside={
    <>
      <VerityMark />
      <p>This site is built with <Link href="/verity">Verity</Link>, my design system.</p>
    </>
  }
/>
```

Keep it to a sentence or two: it’s beside the call to action, not a second one.

## Color

The block’s background is `--verity-color-background-subtle`: brand 800 in each theme, one step lighter than the page, so the Footer stands apart from the page’s content without a divider, and follows the theme. Its text uses the usual content colors.

**The links use the body text colors.** On this fill, the usual link color is below 4.5:1 (4.47:1 in Blue, 4.11:1 in Red). So the Footer tells the Links inside it to use `--verity-color-content-default` at rest and when visited, and `--verity-color-content-default-hover` on hover and press: 11.6:1 and up. The underline still marks them as links. Disabled links keep their own color. The site passes nothing: the Footer sets the colors (see **Actions › Link**).

| Link state | Token |
|---|---|
| Default and visited | `--verity-color-content-default` |
| Hover and active | `--verity-color-content-default-hover` |
| Disabled | `--verity-link-color-content-disabled` |

## Space

| Space | Token |
|---|---|
| Inside the block, around its content | `--verity-padding-md` |
| Between the call to action and aside, and the copyright | `--verity-spacing-lg` |
| Between the call to action and the aside, side by side or stacked | `--verity-spacing-lg` |
| Inside the call to action: heading, text, actions | `--verity-spacing-sm` |
| Between the button and the second action | `--verity-spacing-xs` |
| Between the things in the aside | `--verity-spacing-sm` |
| Outside the footer | None. Whatever holds it, like Shell, sets the space above it. |

The corners are `--verity-border-radius-md`.
