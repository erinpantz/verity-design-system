# Footer

The site’s footer: a row of cards for the things you most want a visitor to do, then the copyright line.

<Canvas of={FooterStories.Default} />

## When to use

- **Once per page, at the end,** after the page’s content. `Shell` puts it there.
- **With a few `ActionCard`s,** usually three, given the same weight: on Erin’s site, Let’s chat, Verity, and Music.
- **Not for the end of a section or an article.** Use `Divider` and a `Section` there.
- **Not for the site’s page links.** The nav is fixed to the top of every page, so links to the pages would repeat it.

## Accessibility

A Footer renders a `<footer>`. Outside `<main>`, it’s the page’s footer landmark (`contentinfo`), so screen readers can jump to it. Its links and buttons go through `LinkProvider`: with a site’s router, links to the site’s pages change the page in the app, and other sites stay plain links (see **Actions › LinkProvider**).

For each card, a screen reader reads the heading, then the body, then the buttons. The IconTile is decorative and hidden, so it isn’t read.

| Part | What it renders | What to do |
|---|---|---|
| Each card | An `ActionCard` you pass in `cards` | Set `headingLevel={2}`: the Footer has no heading of its own, so the cards’ headings are its top level. |
| A card’s buttons | A `Button`, and optionally `IconButton`s | Start each label with a verb: “Book a call.” For a page on another site, set `opensInNewTab`. |
| A card that isn’t ready yet | A disabled `Button` with `tooltip` | “Check it out,” disabled, with “Coming soon.” It stays in the tab order, so keyboard users can reach it and hear why. |
| Copyright | A paragraph: `© {year} {name}` | Pass only the name. The year comes from today’s date, so it never goes stale. |

## Layout

The Footer is wide: it spans the page up to `--verity-content-wide-width` (1824), like a wide image, so it reads as the page’s closing band rather than one more block in the column.

The cards share a `Grid` with `itemWidth="lg"` and `fillRows`, so they wrap by the Footer’s own width, not the screen’s:

| Footer width | The cards |
|---|---|
| Room for three at `--verity-grid-item-min-width-lg` (400 on XL and Large, 300 on Medium and Small) | Three across, equal widths |
| Room for two | Two across, then the third alone on the next row, at the full width |
| Less than two | One per row |

In Shell, that’s three across at 1920; two plus one at 1280 and 768; and one per row at 375.

In a row, every card is as tall as the tallest, and each card’s buttons sit at its bottom, so they line up across the row (see **Content blocks › ActionCard**).

## Color

The Footer has no fill, padding, or rounded corners of its own: the cards carry the surface, `--verity-color-background-subtle`, and the page shows between them. A `Link` in a card’s body takes the body text colors, which ActionCard sets for its fill.

The copyright is `meta-default` in `--verity-color-content-subtle`.

## Space

| Space | Token |
|---|---|
| Between cards, and between rows | `--verity-spacing-md` (the Grid’s `md` gap) |
| Between the cards and the copyright | `--verity-spacing-md` |
| Inside each card | `--verity-padding-md` (ActionCard’s) |
| Outside the footer | None. Whatever holds it, like Shell, sets the space above it. |

At the end of a page, Shell’s ThemeToggle sits in the copyright’s row, at the right, below the cards, so it never covers one.

## In Figma

| Figma | Code |
|---|---|
| Component `Footer`, on the Layout page | `<Footer />` |
| The `Cards` Grid (`Item width=lg`, `Fill rows=true`, `Width=wide`) and its ActionCards | `cards`: pass the ActionCards. The Footer makes the Grid. |
| Property `Copyright` | `copyrightName`. The `© {year}` part is added for you, with this year. |
| Property `Width` (`constrained` only) | Nothing: Figma requires a variant property, and it does nothing |
| The cards’ headings, Level 3 in Figma | `headingLevel={2}` in code, as Figma’s description says |
| Verity’s “Check it out” | Disabled in code, with the tooltip “Coming soon,” until Verity’s Storybook is public. Figma shows it enabled. |
| Variables `footer/call-to-action/min-width`, `footer/call-to-action/max-width`, and `footer/links/min-width` | Unused since 0.11.0: the old Footer’s layout |
